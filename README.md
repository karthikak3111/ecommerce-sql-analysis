# E-Commerce SQL Project

## Project Overview
Analyzed 25K+ e-commerce orders using SQL to identify:
- Sales trends
- Top-performing products
- Customer behavior
- Return analysis
- Delivery performance
- Payment insights

## Tools Used
- MySQL
- SQL
- GitHub

## Dataset
E-commerce order dataset containing:
- Orders
- Customers
- Products
- Revenue
- Delivery details
- Ratings

## Business Questions Solved
1. Total revenue analysis
2. Top selling categories
3. Monthly sales trends
4. Return rate analysis
5. Repeat customer analysis
6. Device-wise revenue analysis
7. Payment method insights
8. Delivery performance analysis

## SQL Concepts Used
- GROUP BY
- ORDER BY
- Aggregate Functions
- CASE WHEN
- Window Functions
- RANK()
- Running Totals
- CTEs

## Key Insights
- Electronics generated highest revenue
- Mobile users placed most orders
- Repeat customers generated higher revenue
- Higher discounts increased return rates
